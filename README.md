# مِحراب

تطبيق ويب (PWA) عربي: مواقيت الصلاة والأذان، اتجاه القبلة، الورد اليومي من القرآن، الأذكار والسبحة، ورمضان.

- المواقيت تُحسب على الجهاز (مكتبة adhan) وتعمل دون اتصال.
- يُنشر تلقائيًا على GitHub Pages عند كل دفع إلى `main`.

```bash
npm install
npm run dev     # تطوير
npm run build   # بناء ثابت في out/
```

المصادر: الأذكار من «حصن المسلم» (مستودعات MIT)، ونص المصحف من Tanzil عبر api.alquran.cloud.
